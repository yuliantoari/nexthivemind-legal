Privacy Policy

NEXT Hivemind · Last updated: 9 November 2026

1. Who we are

NEXT Hivemind is a personal tool built and used by one person, the owner of the YouTube channel NEXT Xinema. It runs on the owner's own computer. Contact: nekztxinema@gmail.com.

2. Data the tool accesses

With the owner's explicit consent through Google's OAuth screen, the tool accesses only data of the owner's own YouTube channel:

  • Channel and video information: titles, descriptions, tags, publish status and schedule, thumbnails.
  • YouTube Analytics: views, watch time, audience retention, traffic sources, subscribers and estimated revenue of the owner's channel.
  • If the owner enables editing: the ability to update the metadata of the owner's own videos (title, description, tags, thumbnail, schedule). Each change is made only after the owner clicks a button in the tool.

3. How the data is used

The data is used only to show the owner how his channel performs, to suggest improvements, and to apply the changes the owner chooses. It is not used for advertising, profiling, or any purpose unrelated to the owner's own channel.

4. Storage and sharing

All data and access tokens are stored locally on the owner's computer. The data is not sold, shared, transferred, or disclosed to any third party. No Google user data is sent to any server operated by the developer, because the tool has no such server. The tool does not collect data about any person other than the owner.

5. Google API Services User Data Policy

NEXT Hivemind's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Retention and revoking access

Data stays on the owner's computer until the owner deletes it. The owner can revoke the tool's access at any time at myaccount.google.com/permissions, and can delete the stored token file on his computer.

7. Changes

If this policy changes, the date above will be updated.
